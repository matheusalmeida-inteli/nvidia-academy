Identificar, qualificar e nutrir startups brasileiras AI-native para o programa NVIDIA Inception.

Contexto de negócio · TAPI §1

O problema

  • Grandes labs de IA (OpenAI, Anthropic, DeepMind) subiram na cadeia de valor
  • Passaram de fornecedores de modelo para APIs, agentes e produtos finais
  • Ameaça direta a startups que são apenas wrappers de LLM
  • Oportunidade para startups AI-native: software, dados próprios, automação e serviço especializado
Pergunta norteadora · TAPI §3

A pergunta

Como a NVIDIA pode identificar, atrair e nutrir startups brasileiras AI-native em um contexto no qual os grandes labs de IA ameaçam quem depende de wrappers de LLM?

Arquitetura

Pipeline multi-agente (LangGraph)

Query Planner→ Retriever→ Extractor→ Classifier→ Evidence Validator→ Supervisor→ NVIDIA RAG→ Recommendation→ Briefing
  • Cada nó volta ao Supervisor: replan, retry ou degradação graciosa
  • Todo nó tem fallback rule-based — pipeline nunca quebra
  • Camadas: Next.js → FastAPI → LangGraph → PostgreSQL + Qdrant + RAG
Exemplo real

De "uma frase" ao briefing

"AI-native startups de fintech usando LLMs"

  • Query Planner converte em keywords e filtros
  • Retriever devolve até 25 startups do PostgreSQL
  • Extractor monta perfil: stack, casos de uso, gaps, moat
  • Classifier → ai_native · ai_enabled · non_ai + fit score
  • Evidence Validator checa evidências rastreáveis
  • RAG + Recommendation priorizam techs NVIDIA com justificativa
  • Briefing entrega o relatório executivo pronto
